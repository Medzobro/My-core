## Re-running scans

```bash
# From repo root
cd lost_eth_scanner

# Refresh any output:
python3 deep_audit.py                # rebuilds results/deep_audit_results.json
python3 cryptopunks_pending_scan.py  # rebuilds results/cryptopunks_pending.json
# etc.
```

All scanners write to their own JSON in this folder.
